# 智能资产配置器 Pro Max

专业级投资组合管理与再平衡 PWA 工具，纯前端离线可用。

**在线地址**: https://unplage.github.io/invest/

---

## 功能特性

### 📊 仪表盘
- 总资产净值、累计投入、累计收益、最大偏离度实时展示
- 资产配置现状（地域分布 + 标的详情条形图）
- 待办事项提醒（再平衡提醒 + 定期投资到期提醒）
- 📈 **实时行情**：支持 Alpha Vantage / Finnhub API，展示全球主要指数/ETF 实时价格
- 📅 最近活动时间线

### 💰 新增投资
- 投资日期、金额、备注记录
- **份额/单价模式**：精确追踪每个标的的持仓成本
- 自定义权重配置（临时调整，不影响默认设置）
- 分配方案预览 + 投资提示
- 草稿箱功能（保存/载入草稿）

### ⚖️ 再平衡
- 输入当前各标的持仓市值
- 自动载入上次再平衡持仓数据
- 目标权重配置（预设方案或自定义）
- 调仓建议（买入/卖出/持有）+ 偏离度分析
- 预估交易费用计算

### 📈 深度分析
- 投资行为分析（次数、累计投入、平均单笔、频率）
- 总收益率、年化收益率、最大回撤、波动率、夏普比率
- Chart.js 图表：地域分布饼图、月度投资柱状图、持仓横向柱状图
- 时间范围筛选（全部/本年/本季/本月）

### 📜 历史记录
- 全部/投资/再平衡 筛选
- 关键字搜索
- 📤 导出 JSON / CSV / Markdown
- ✏️ 编辑记录（修改日期、金额、分配详情）
- 查看详情 + 删除记录

### ⚙️ 配置
- **预设方案**：全球平衡 / 保守稳健 / 积极进取 / 等权重
- 自定义配置方案保存/载入
- **自定义标的**：添加/编辑/删除自定义投资标的（名称、代码、地区、颜色）
- **行情 API 设置**：Alpha Vantage / Finnhub，API Key 配置，手动添加行情标的代码
- 再平衡阈值、交易费用率
- 自动备份、数据导入/导出（完整迁移 + 增量合并）
- **密码保护**：SHA-256 加密，锁屏验证
- **操作日志**：所有数据变更的审计跟踪

### 📅 定期投资计划 (DCA)
- 创建定时定额投资计划（每周/双周/每月/每季度）
- 到期自动提醒（浏览器通知 + 应用内待办）
- 一键载入计划到投资页面执行

### 🔐 安全与隐私
- 所有数据存储在浏览器本地 IndexedDB + localStorage
- 密码保护（SHA-256 哈希）
- 无服务器端存储，数据完全由用户掌控

### 📦 数据管理
- 完整数据导出/导入（换机迁移）
- CSV / Markdown 格式导出
- 自动备份（每次操作后自动导出）

---

## 技术架构

- **纯前端 PWA**：单页应用（SPA），Service Worker 离线缓存
- **存储**：IndexedDB (操作记录) + localStorage (配置/缓存)
- **图表**：Chart.js v4.4.0
- **行情 API**：Alpha Vantage / Finnhub
- **图标**：内联 SVG（无需外部图标资源）
- **无框架依赖**：纯原生 JavaScript + CSS

## 本地开发

项目为纯静态页面，无需构建工具：

```bash
# 克隆仓库
git clone https://github.com/unplage/invest.git

# 使用任意 HTTP 服务器预览
npx serve invest/
# 或
python3 -m http.server -d invest/ 8080
```
